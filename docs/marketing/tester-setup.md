# 구글 그룹으로 비공개 테스터 받기

대표가 순서대로 따라 하는 문서. 2026-09-26에 공식 도움말을 읽고 썼다.
**확인 못 함**이라고 적은 곳은 도움말에서 찾지 못했거나 화면을 직접 볼 수 없었던 부분이다 — 실제 화면과 다르면 화면을 따르고 이 문서를 고친다.

왜 이메일 목록이 아니라 그룹인가: 테스터 이메일을 한 명씩 받아 적지 않아도 되고, 테스터에게 공지를 한 번에 보낼 수 있다.
Play Console도 비공개 테스트 테스터를 이메일 목록 또는 Google 그룹으로 받는다.

## 0. 먼저 되어 있어야 하는 것

- Play Console 개발자 계정 가입·신원 확인 (`docs/STORE_RELEASE.md` 0장)
- 앱 만들기와 앱 설정(스토어 등록정보, 데이터 안전, 콘텐츠 등급 등) (`docs/STORE_RELEASE.md` 4장)
- 서명한 AAB (`docs/STORE_RELEASE.md` 3장)

구글 그룹(1장)은 위 준비와 **상관없이 오늘 만들 수 있다.** 그룹부터 만들어 모집을 시작하고, Play 쪽은 그 사이에 진행한다.

## 1. 구글 그룹 만들기 (10분)

도움말: [그룹 만들기 및 그룹 설정 선택](https://support.google.com/groups/answer/2464926?hl=ko)

1. [groups.google.com](https://groups.google.com/)에 앱을 올릴 때 쓰는 구글 계정으로 로그인
2. 위쪽 **그룹 만들기**
3. 입력
   - **그룹 이름**: `결정 노트 테스터`
   - **그룹 이메일**: 예) `decision-note-testers` → `decision-note-testers@googlegroups.com`이 된다. 이 주소를 2장에서 쓴다
   - **그룹 설명**: `결정 노트(안드로이드) 비공개 테스트 참여자 모임입니다. 가입 후 안내 메일의 링크로 테스트에 참여할 수 있어요.`
4. 개인정보 설정 — 권하는 값

   | 항목 | 권하는 값 | 이유 |
   |---|---|---|
   | 그룹을 검색할 수 있는 사용자 | 웹의 모든 사용자 | 링크를 받은 사람이 그룹 페이지를 열 수 있게. **이 값이 꼭 필요한지는 확인 못 함** — 더 좁혀도 링크로 가입되는지 대표가 다른 계정으로 한 번 시험해 보면 확실하다 |
   | 그룹에 가입할 수 있는 사용자 | **누구나 가입할 수 있음** | 승인 없이 바로 가입. "누구나 요청할 수 있음"으로 하면 대표가 한 명씩 승인해야 한다 |
   | 대화를 볼 수 있는 사용자 | 그룹 회원 | 공지는 테스터만 보면 된다 |
   | 게시할 수 있는 사용자 | 그룹 소유자(또는 관리자) | 테스터끼리 스팸이 오가지 않게 |
   | 회원을 볼 수 있는 사용자 | 그룹 소유자(또는 관리자) | **테스터끼리 서로의 이메일이 보이지 않게** |

   위 다섯 항목 이름과 '가입' 선택지 다섯 개(초대된 사용자만 / 조직 내 모든 사용자가 요청·가입 / 누구나 요청 / 누구나 가입)는 도움말에서 확인했다.
   아래 세 칸(대화·게시·회원 보기)의 **선택지 목록 자체는 확인 못 함** — 도움말에 역할 이름(그룹 회원·관리자·소유자)만 나온다.
   그룹 설정에 '회원 이메일 주소를 볼 수 있는 사용자' 항목이 따로 있다면 그것도 소유자·관리자로 둔다
   ([게시·조회 권한 도움말](https://support.google.com/groups/answer/2464975?hl=en)에 이 설정이 언급된다).
5. **그룹 만들기** → 몇 분 기다리면 활성화된다 (도움말)
6. 브라우저 주소창의 그룹 주소(`https://groups.google.com/g/그룹이메일앞부분` 형태)를 복사해 둔다 → 이것이 **[테스터 그룹 링크]**
   (주소 형태는 화면을 직접 보고 확인한 것이 아니다. 주소창에 뜬 것을 그대로 쓴다)
7. **시험**: 다른 구글 계정(가족 폰 등)으로 그 링크를 열어 '그룹 가입'이 바로 되는지 본다

## 2. Play Console 비공개 테스트에 그룹 연결

도움말: [공개, 비공개, 내부 테스트 설정](https://support.google.com/googleplay/android-developer/answer/9845334?hl=ko)

1. Play Console → 앱 선택 → **테스트 및 출시 > 테스트 > 비공개 테스트**
2. 기본 트랙을 쓰거나 오른쪽 위 **트랙 만들기**로 새 트랙
3. **테스터** 탭 → **Google 그룹** 선택 → `decision-note-testers@googlegroups.com` 입력
4. **의견 URL 또는 이메일 주소** — 테스터 의견을 받을 곳. 도움말이 요구하는 항목이다. 3장 참고
5. 저장
6. 새 버전 만들기 → 서명한 AAB 업로드 → 출시 노트 → 검토 → 출시(심사 제출)
7. 배포 국가·지역에 **대한민국**이 들어 있는지 본다. 도움말은 국가 변경이 모든 트랙에 함께 적용된다고만 적고 있다 — 비공개 트랙 화면에서 국가를 따로 고르는지는 **확인 못 함**

**옵트인 링크는 앱 상태가 '게시됨'일 때만 보인다.** '초안'이나 '게시 대기 중'이면 링크가 없다 (도움말).
심사가 끝나 '게시됨'이 되면 **테스터** 탭에서 공유 링크를 복사한다 → 이것이 **[테스트 참여 링크]**.
심사에 며칠 걸리는지는 공식 수치를 **확인 못 함**.

## 3. 의견 받을 곳 정하기

Play Console에 넣어야 하고, 프로덕션 신청서가 "테스터에게 받은 의견 요약"과 "그걸 보고 무엇을 바꿨는지"를 묻는다
([새 개인 개발자 계정의 앱 테스트 요구사항](https://support.google.com/googleplay/android-developer/answer/14151465?hl=ko)).
그래서 의견이 한곳에 모이는 게 좋다.

- **권함 — 구글 폼** (대표가 만든다). 질문은 세 개면 충분하다
  1. 어떤 고민을 적어봤나요? (선택, 한 줄)
  2. 어디서 멈칫하거나 헷갈렸나요?
  3. 결과 화면을 보고 든 생각은? (선택)
  이름·이메일은 묻지 않는다. 폼 주소가 **[의견 보낼 곳]**
- 또는 앱 개인정보 화면에 이미 공개된 문의 메일 주소

## 4. 테스터가 누르는 순서

테스터에게는 스레드 모집 글 첫 댓글(`posts/2026-09-28-threads-tester-recruit.md`)이 이 순서를 안내한다.

1. **그룹 가입** — [테스터 그룹 링크] → '그룹 가입'
   - 폰의 플레이 스토어에 로그인된 **같은 구글 계정**이어야 한다
   - 가입 창에서 '이메일 업데이트' 받기를 켜 두면 공지 메일을 받는다 ([그룹 찾기 및 가입 도움말](https://support.google.com/groups/answer/1067205?hl=ko))
   - Play Console 도움말: "사용자는 테스트에 참여하기 전에 그룹에 가입해야 합니다" — 순서가 바뀌면 안 된다
2. **테스트 참여(옵트인)** — [테스트 참여 링크] → 테스터의 책임에 대한 설명과 참여 버튼이 나온다 → 참여
   - 버튼 이름은 영문 화면 기준 'Become a tester'로 안내하는 글이 많다. **한국어 화면의 버튼 이름은 확인 못 함** — 그래서 모집 글에는 '테스터 되기'로 적었다. 대표가 처음 한 번 눌러 보고 실제 이름으로 고친다
3. **설치** — 참여 페이지의 플레이 스토어 링크, 또는 [플레이 스토어 링크]
   - 참여 직후엔 스토어에 안 보일 수 있다 (얼마나 걸리는지는 확인 못 함)
4. **14일 동안 나가지 않기** — 중간에 나갔다 다시 들어오면 그 사람의 14일은 다시 센다 (도움말)
   - 앱을 지우면 어떻게 되는지는 공식 도움말에서 **확인 못 함**. 그래서 "지우지 말아 주세요"보다 "나가지 말아 주세요"로만 부탁했다

### 옵트인 링크가 생긴 날 — 그룹 공지 (그룹에 새 대화로 올리거나 그룹 주소로 메일)

```
제목: [결정 노트] 테스트 참여 링크가 열렸어요

그룹에 가입해 주셔서 고맙습니다.
구글 심사가 끝나서 이제 설치할 수 있어요.

1. 테스트 참여: [테스트 참여 링크]
   → '테스터 되기'를 눌러 주세요 (그룹에 가입한 같은 계정으로)
2. 설치: [플레이 스토어 링크]
   (바로 안 보이면 조금 뒤에 다시 열어 주세요)

부탁드리는 것
- 14일 동안 테스터에서 나가지 말아 주세요. 나갔다 들어오면 다시 세야 해요
- 그 사이 진짜 고민 하나를 끝까지 적어봐 주세요
- 헷갈린 점 한 줄이면 충분해요: [의견 보낼 곳]

안드로이드 7.0 이상에서 돼요. 궁금한 건 이 메일에 답장 주세요.
```

### 7일째 — 중간 인사 (한 번만)

```
제목: [결정 노트] 일주일 지났어요

테스트에 함께해 주셔서 고맙습니다. 절반 왔어요.
아직 고민 하나를 끝까지 적어보지 않으셨다면, 작은 거라도 한 번 해봐 주세요.
(작은 고민도 괜찮아요. 선택지 두 개부터 돼요)

헷갈렸던 점 한 줄: [의견 보낼 곳]
받은 의견으로 고친 건 다음 메일에 알려드릴게요.
```

## 5. 숫자 보는 곳

- **그룹 가입 수**: 그룹 페이지의 회원 목록
- **옵트인 수**: Play Console에서 비공개 테스트 참여자 수를 어디서 보는지는 **확인 못 함**. 대표가 화면에서 찾으면 여기에 적는다
- **14일 시계**: 12번째 옵트인 날을 `log.md`에 적는다. 그 뒤 14일을 채우면 대시보드에서 **프로덕션 신청** (도움말)
