# 스레드 ① 테스터 모집 — 2026-09-28 (월) 20:00~21:00

1주차 첫 글. 오랜만에 돌아온 인사를 겸한다. 링크는 전부 첫 댓글에.

- **올리기 전 조건**: 구글 그룹이 만들어져 있을 것 (`../tester-setup.md` 1장). Play 옵트인 링크는 아직 없어도 된다 — 첫 댓글 B안을 쓴다
- **붙일 파일**: `docs/promo/decision-note-promo.mp4` (36초, 세로. 소리 없음 — 스레드는 소리 없이 올려도 된다)
- **주제 태그 (하나만)**: `1인개발` — 태그가 없으면 이것 없이 올려도 된다
- **올린 뒤**: 첫 한 시간은 답글에 바로 답한다. 링크를 따로 묻는 사람에게는 "첫 댓글에 있어요"

## 본문 (태그 포함 500자 이내)

```
오랜만에 스레드 다시 시작해요. 그동안 혼자 안드로이드 앱을 하나 만들었어요.

이사할까, 그냥 살까. 이직할까, 버틸까.
이런 고민 몇 주씩 끌어본 적 있나요?

'결정 노트'는 그럴 때 쓰는 노트예요.
선택지를 적고, 나한테 중요한 기준을 순서대로 놓고, 하나씩 점수를 매기면
지금 내 기준에서 어느 쪽이 더 맞는지 이유와 함께 보여줘요.
정답을 골라주진 않아요. 정하는 건 나예요.

구글 플레이에 정식으로 올리려면 테스터 12명이 14일 동안 참여해야 해서, 함께해 주실 분을 찾고 있어요. 넉넉하게 20명이 목표예요.

· 안드로이드 폰이면 돼요 (아이폰 버전은 아직 없어요)
· 광고 없고, 로그인 없어요
· 적은 고민은 기본적으로 내 폰에만 저장돼요

참여 방법은 첫 댓글에 적어둘게요.
```

## 첫 댓글 — A안 (Play 옵트인 링크가 있을 때)

```
참여 방법 (3분이면 돼요)
폰의 플레이 스토어에 로그인된 구글 계정 하나로 끝까지 해주세요.

1. 그룹 가입 → '그룹 가입'
[테스터 그룹 링크]

2. 테스트 참여 → '테스터 되기'
[테스트 참여 링크]

3. 설치 (바로 안 보이면 조금 뒤에 다시)
[플레이 스토어 링크]

부탁드리는 것
· 14일 동안 테스터에서 나가지 말아 주세요. 나갔다 들어오면 다시 세야 해요
· 그 사이 진짜 고민 하나를 끝까지 적어봐 주세요
· 헷갈린 점 한 줄이면 충분해요 → [의견 보낼 곳]

안드로이드 7.0 이상에서 돼요.
```

지금 292자. 링크 네 자리를 실제 주소로 바꾸면 늘어난다 — 예시 주소로 넣어 보니 454자. 붙여넣은 뒤 스레드 글자 수 표시가 500을 넘지 않는지 본다.

## 첫 댓글 — B안 (아직 Play 심사 중일 때)

```
참여 방법

1. 지금은 테스터 그룹에만 가입해 주세요
[테스터 그룹 링크]
'그룹 가입'을 눌러 주세요. 폰의 플레이 스토어에 로그인된 구글 계정으로 해야 해요.

2. 구글 심사가 끝나면 설치 링크를 그룹 메일로 한 번 보내드릴게요.
그 메일의 '테스트 참여' 링크에서 '테스터 되기'를 누르고 설치하면 끝이에요.
(그룹 가입할 때 '이메일 업데이트 받기'를 켜 두시면 놓치지 않아요)

부탁드리는 것
· 참여한 뒤 14일 동안 테스터에서 나가지 말아 주세요
· 그 사이 진짜 고민 하나를 끝까지 적어봐 주세요
· 헷갈렸던 점 한 줄이면 충분해요 → [의견 보낼 곳]

안드로이드 7.0 이상에서 돼요.
```

옵트인 링크가 생기면 **A안을 새 댓글로 달고 B안 댓글은 지운다.** (스레드 글 수정은 올린 직후 잠깐만 된다는 정리가 있으나 확인 못 함 — 그래서 고치지 말고 새로 단다.)
그리고 그룹에 공지 메일을 한 번 보낸다 (`../tester-setup.md` 4장).
