# 의사결정 지원 앱 디자인 시스템

> 팔레트 A(원고지) 기준 확정. 이 문서가 단일 기준이다. 화면을 새로 만들 때 여기 없는 값을 새로 만들지 말고, 필요하면 이 문서에 먼저 추가한다.

## 1. 색

```css
:root{
  --desk:    #EFECE5;  /* 종이 바깥 책상 */
  --paper:   #FAF9F6;  /* 종이 배경 */
  --rule:    #EAE7DF;  /* 괘선(가로줄) */
  --card:    #FFFFFF;  /* 카드 배경 */
  --border:  #E3DFD5;  /* 카드 테두리 */
  --dashed:  #D2CCBF;  /* 점선 테두리(추가 버튼 등) */
  --ink:     #23201C;  /* 본문, 확정 버튼 배경 */
  --soft:    #5A554C;  /* 설명문 */
  --meta:    #6E695C;  /* 보조 텍스트·날짜·타이머 (2026-09-19 대비 미달로 #8A8478→#6E695C 수정) */
  --pen:     #B3402B;  /* 빨간 펜 — 사용자의 손자국 전용 */
  --pen-hover: #8E3120;
  --accent:  #2F6A5E;  /* 확신도·만족도·적합도 앞선 쪽 — 단일 강조색으로 통일 */
  --hl:      #F2D98D;  /* 형광펜, 화면당 최대 1곳 */

  /* 선택지 고유색 (2026-09-20 추가) — ①②③④⑤가 각자 갖는 색.
     비교 화면에서 순위가 바뀔 때 "무엇이 무엇을 제쳤는지" 눈으로 따라가게 한다. */
  --alt-1:   #B3402B;  /* = --pen */
  --alt-2:   #2F6A5E;  /* = --accent */
  --alt-3:   #78591F;
  --alt-4:   #4A6280;
  --alt-5:   #6E695C;  /* = --meta */
  --alt-dim: 0.55;     /* 앞서지 않은 쪽 막대의 불투명도 */
}
```

### 색 사용 규칙

| 색 | 쓰는 곳 | 절대 안 쓰는 곳 |
|---|---|---|
| `--ink` | 본문, 제목, 확정 버튼(검정 배경) | 강조 표시 |
| `--pen` | 밑줄·체크·동그라미·취소선·도장·손글씨 메모 | 상태 배지, 버튼 배경 |
| `--accent` | 확신도 버튼, 만족도 버튼, 결과에서 앞선 선택지 막대·아이콘, "통과" 배지 | 링크, 제목 |
| `--hl` | 결과 화면의 결론 문장 1곳 | 여러 곳 동시에 |

- **확신도·만족도는 전부 `--accent` 하나로 통일한다.** 별도 색을 만들지 않는다.
- **"앞선 선택지"는 2026-09-20부터 예외다.** 선택지마다 `--alt-1`~`--alt-5`를 갖고, 앞선 쪽은 그 색을 그대로, 나머지는 `--alt-dim`(55%)으로 흐리게 칠한다. 앞선 쪽이 눈에 띄어야 한다는 원래 의도는 그대로다 — 방법만 "혼자 색이 있음"에서 "혼자 진함"으로 바뀐다.
  - 쓰는 곳은 **선택지를 나란히 비교하는 화면뿐**이다: 결과 · 직접 조정해보기 · 내가 매긴 표. 직감·필수조건·평가·확정·회고에서는 `--pen`을 그대로 쓴다. 앱 전체를 색으로 칠하면 `--pen`이 "사용자의 손자국"이라는 뜻을 잃는다.
  - 색은 **선택지 번호에 붙는다**(①은 항상 `--alt-1`). 순위가 아니라 정체성이다.
- `--pen`과 `--accent`는 역할이 다르다: 펜은 "사용자가 쓴 흔적", 강조는 "계산 결과가 가리키는 쪽".
- 다크모드는 지원하지 않는다.

| `--ink` / `--card` | 16.22:1 | 4.5:1 | 통과 |
| `--soft` / `--paper` | 7.03:1 | 4.5:1 | 통과 |

### 선택지 고유색 대비 (2026-09-20 검증)

막대는 비텍스트 그래픽 요소라 3:1, 번호·이름은 글자라 4.5:1이 기준이다.

| 색 | 막대 / `--rule` | 글자 / `--paper` | 결과 |
|---|---|---|---|
| `--alt-1` #B3402B | 4.61:1 | 5.41:1 | 통과 |
| `--alt-2` #2F6A5E | 5.08:1 | 5.96:1 | 통과 |
| `--alt-3` #78591F | 5.23:1 | 6.14:1 | 통과 (후보 #8A6B2F가 4.72:1로 여유가 없어 어둡게 수정) |
| `--alt-4` #4A6280 | 5.07:1 | 5.95:1 | 통과 |
| `--alt-5` #6E695C | 4.43:1 | 5.20:1 | 통과 |

앞서지 않은 막대(`--alt-dim` 55%)는 트랙 대비 1.88~2.05:1로 3:1에 미달한다. 다만 이는
**지금 쓰는 `--bar-rest`(1.84:1)와 같은 수준**이고, 길이로 값을 읽는 보조 막대라 의도적으로
낮춘 것이다. 앞선 쪽은 위 표대로 전부 통과한다.

## 2. 타이포그래피

| 용도 | 폰트 | 굵기 | 자간 |
|---|---|---|---|
| 제목·질문 문장·입력 필드 | Gowun Batang | 700 | 기본값(조정 없음) |
| 본문·버튼·라벨 전체 | IBM Plex Sans KR | 400 / 500 / 600 | 기본값 |
| 손글씨(사용자의 흔적) | **KCC김환기체** | 400 | **조정 없음** |

### 손글씨 폰트 — KCC김환기체

- **출처**: 한국저작권위원회 공유마당, 김환기 화백의 손글씨를 기증받아 개발
- **라이선스**: OFL(Open Font License) — 폰트 파일 자체를 유료 판매하지 않는 한 자유 이용·수정·재배포 가능
- **적용 범위**: `direction`, `처음 마음은 ①`, `여기부터 ①`, `결정함`, `이런 문장도 좋아요`, `세 개면 충분해요`, 회고 화면의 인용구, **매트릭스 화면의 점수·①②③·무게 비율·적합도 라벨** — 사용자가 직접 남긴 것처럼 보이는 요소에만 사용. 자간은 원본 그대로 둔다.
- **임베딩 방식**: 전체 폰트(12,264자)를 그대로 불러오지 않고, 화면에 실제로 쓰이는 글자만 골라 woff2로 서브셋한 뒤 `@font-face`에 base64로 직접 삽입. 외부 폰트 서버 요청이 없어 로딩 실패 위험이 없다.
- **낱글자 서브셋** (2026-09-20 추가): 문구뿐 아니라 `0-9`, `%`, `①②③④⑤`, `낮음/보통/높음`도 서브셋에 담는다. 매트릭스 화면에서 **사용자가 직접 매긴 점수**를 손글씨로 찍기 위해서다 — 이것도 "사용자가 직접 남긴 것"이라 §2의 적용 범위 안에 있다.
  선택지·기준 **이름은 손글씨로 쓰지 않는다.** 사용자가 직접 치는 글자라 어떤 글자가 나올지 알 수 없고, 전부 담으려면 원본 1.9MB를 통째로 실어야 한다. 이름은 본문 서체(Gowun Batang)로 남는다.
  서브셋 목록은 `src/styles/ink-phrases.ts`의 `INK_PHRASES`와 `INK_GLYPHS`가 유일한 출처이고, `npm run font:subset`이 woff2와 `base.css`의 `unicode-range`를 함께 갱신한다.
- **이전 검토**: Gaegu 700(구글 폰트) → Nanum Pen Script(자간 +10%) 순으로 검토했으나, 최종적으로 KCC김환기체로 확정하며 자간 조정을 없앴다. 검토 과정은 프로토타입의 "모션·손글씨 레퍼런스" 보드에 남아 있다.

## 3. 종이 · 배경

```css
.desk{ background: var(--desk); padding: 8px; }
.paper{
  background: var(--paper);
  border: 1px solid #DDD8CC;
  border-radius: 3px;
  box-shadow: 0 2px 10px rgba(35,32,28,0.06);
}
.margin-line{ /* 종이 왼쪽 세로 여백선 */
  width: 1px; background: rgba(179,64,43,0.22);
}
```

- 화면은 "책상(`--desk`) 위에 놓인 종이 한 장" 구조다. 바깥 여백 8px, 종이에 옅은 테두리와 그림자.
- 종이 왼쪽에는 노트 여백선(빨간 세로선, 22% 불투명도)이 있다.
- 카드는 종이보다 밝은 순백(`--card`)으로 올려서 떠 보이게 한다.
- 홈 화면 배경에만 `--rule` 가로 괘선(31~32px 간격)을 반복한다.

## 4. 모션 토큰

| 이름 | 시간 | 용도 |
|---|---|---|
| `write-on` | 300ms | 질문·결과 문장이 왼쪽에서 쓰이듯 나타남. 줄마다 80ms 지연 |
| `ink-draw` | 380ms | 밑줄·체크·동그라미·취소선. `stroke-dashoffset`으로 펜이 긋는 것처럼 |
| `settle` / `liftIn` | 220~260ms | 카드·후보·기준이 살짝 떠서 내려앉음 |
| `hilite` | 320ms | 형광펜, 화면당 최대 1곳 |
| `strike` | 420ms | 필수조건 탈락 취소선, 이어서 opacity 0.45 |

- 이징은 전부 `cubic-bezier(.22,.9,.24,1)`.
- 항목 간 지연 간격은 80ms.
- **한 화면의 진입 모션 전체는 900ms 안에 멈춘다.**
- 뒤로 가기는 모션을 역재생하지 않고 페이드로 끝낸다.
- `prefers-reduced-motion`에서는 전부 생략하고 최종 상태만 보여준다.
- 반복 루프·떠 있는 로딩·장식용 파티클은 쓰지 않는다.

## 5. 핵심 컴포넌트

| 컴포넌트 | 규칙 |
|---|---|
| 원형 번호(①②③) | Gowun Batang. 기본은 `--pen`. **선택지를 나란히 비교하는 화면**(결과·직접 조정해보기·내가 매긴 표)에서만 선택지 고유색(`--alt-n`)을 쓴다 |
| 진행 단계바 | 7칸, 완료 구간 `--ink`, 미완료 `--border` |
| 확신도/만족도 선택 | 5칸, 선택 이하 칸은 `--accent` 채움, 이상 칸은 투명 테두리만 |
| 결과 적합도 막대 | 선택지 고유색(`--alt-n`). 앞선 쪽은 100%, 나머지는 `--alt-dim`(55%) |
| 순위 변동 | 순서가 바뀌면 줄이 서로 자리를 바꾸며 미끄러진다(420ms `--ease`). 텔레포트하면 무엇이 무엇을 제쳤는지 볼 수 없다 |
| 필수조건 탈락 | `--accent` 배지 유지, 텍스트에 `--pen` 취소선 |
| 결정 도장 | 원형, `--pen` 테두리, KCC김환기체로 "결정함" |
| 카드/섹션 | 배경 `--card`, 테두리 `--border`, radius 14~15px |
| 매트릭스 표 | SVG 한 장. 가로축 선택지(①②③ + 이름), 세로축 기준(이름 + 무게 %), 칸은 손글씨 점수, 기준마다 최고점에 `--pen` 손그림 동그라미. 동점이면 동그라미 없음. 적합도 막대는 넣지 않는다 |
| 순서 바꾸기 | 위/아래 버튼(키보드·보조기기)과 끌기 손잡이(손가락)를 **둘 다** 둔다. 손잡이는 포인터 이벤트로 끌고 `touch-action: none`을 건다 — HTML5 드래그앤드롭은 터치에서 동작하지 않는다 |
| 소리 배지 | 상단 우측 알약형. 켜짐이면 `--accent` 테두리·배경 `--chip-accent`에 막대 3개가 움직임. 누르면 꺼지고 그 선택이 남는다 |

## 7. 구현 전제

- Firebase Auth + Firestore 가정. 고민 본문은 기기 우선 저장, 동기화는 사용자 선택.
- 가중치는 순서 입력만 받고 내부에서 ROC 방식(SMARTER)으로 산출. 사용자에게 숫자를 직접 요구하지 않는다.
- 총점 숫자는 기본 화면에 노출하지 않는다. "적합도"와 "차이를 만든 기준"만 보여준다.
- 민감도는 그래프보다 자연어 문장을 먼저 보여준다.
- 사실/추정/느낌 태그는 결과 화면의 "남은 불확실성" 표시로 그대로 이어진다.

## 9. 금지 목록

- ❌ 확신도·만족도에 강조색(`--accent`) 외의 새 색 쓰기
  - "앞선 선택지"는 2026-09-20부터 §1의 선택지 고유색을 쓴다. 그 다섯 색 밖으로 나가지 않는다.

- ❌ 900ms를 넘는 진입 모션
  - 단 하나의 예외: **매트릭스 화면의 필기 모션**(최대 19초). 화면이 뜰 때마다 반복되는 모션이 아니라 결정당 한 번 보는 연출이라 다른 종류로 본다. 조건 — 건너뛰기를 항상 띄울 것, `prefers-reduced-motion`이면 그리지 않고 완성 상태만 보일 것, 소리는 끌 수 있고 그 선택이 남을 것.
- ❌ 총점 숫자를 기본 화면에 그대로 노출 (매트릭스의 적합도 줄도 `낮음/보통/높음`과 막대로만)
