# Google Play 등록정보 초안

그대로 붙여넣어도 되고, 다듬어서 써도 된다. 글자 수는 각 항목 끝에 적어 뒀다 — Play
콘솔에 붙여넣은 뒤 실제 글자 수 표시로 다시 확인한다.

## 제목 (최대 30자)

```
결정 노트
```

## 짧은 설명 (최대 80자)

```
대안과 기준을 정리하고, 왜 한쪽이 더 맞는지 보여주는 개인 의사결정 노트. 로그인·광고 없이 기기에만 저장됩니다.
```

## 전체 설명 (최대 4000자)

```
중요한 선택 앞에서 생각이 너무 많아졌을 때 쓰는 개인 의사결정 노트입니다.

더 잘 고민하게 만들지 않습니다. 이미 충분히 고민한 걸 정리해서, 결정할 수 있게 도와줍니다.

▪ 대안을 적습니다 (2~5개)
▪ 뭘 기준으로 볼지 적고, 중요한 순서로 놓습니다 — 숫자로 점수를 매기지 않아도 됩니다
▪ 이것만은 안 되는 조건이 있으면 먼저 걸러냅니다
▪ 기준마다 대안을 평가합니다. 잘 모르겠으면 비워둬도 됩니다 — 빈 칸도 결과에 정직하게 반영됩니다
▪ 현재 입력 기준에서 어느 쪽이 더 잘 맞는지, 왜 그런지 문장으로 봅니다
▪ 결과가 얼마나 단단한지(순위가 쉽게 뒤집히는지)도 함께 보여줍니다
▪ 이유를 한 줄 적고 정합니다
▪ 30일 뒤, 그때 결정을 돌아봅니다

정답이나 최선을 단정하지 않습니다. "지금 입력한 기준에서는 이쪽이 더 맞는다"까지만
말합니다. 최종 선택은 항상 당신의 몫입니다.

로그인이 없습니다. 계정도 없습니다. 적은 내용은 기본적으로 이 기기 안에만 저장되고,
원하면 보관함에서 동기화를 켜서 다른 기기와 함께 볼 수 있습니다. 그때도 이름이나
이메일 없이 임의의 식별자로만 연결됩니다.

광고가 없습니다. 추적하지 않습니다. 무료입니다.
```

## 등록 시 참고

- **아이콘(512×512)**: `docs/icon.png`
- **적응형 아이콘 배경색**: `scripts/icon-source.mjs`의 `BG` 값과 동일하게 맞춰져 있음
  (`npm run icons`가 자동 반영)
- **휴대전화 스크린샷**: `docs/screenshots/`에서 2~8장 고른다. 최근 스모크 실행분(번호가
  붙은 파일들) 중 홈·기준·결과·회고 화면을 추천
- **카테고리**: 생산성
- **개인정보 처리방침 URL**: 배포 후 `<호스팅 주소>/privacy`
