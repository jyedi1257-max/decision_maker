## 이용 조건

OFL에 따라 자유롭게 이용·수정·재배포할 수 있다. **폰트 파일 자체를 유료로 판매하는 것만 금지된다.**
이 저장소는 폰트를 판매하지 않으며, 앱에 임베드하기 위한 서브셋 생성에만 사용한다.

## 이 파일이 저장소에 있는 이유

앱에 실제로 실린 `src/assets/fonts/penink.woff2`는 이 원본에서 뽑아낸 **수십 바이트 규모의 서브셋**이다.
손글씨로 찍는 문구(`src/styles/ink-phrases.ts`)가 바뀌면 서브셋을 다시 만들어야 하므로, 재현성을 위해 원본을 함께 둔다.

```bash
npm run font:subset
```

TTF(7.9MB)는 용량이 커서 제외했다. 필요하면 공유마당에서 원본 배포판을 내려받으면 된다.
